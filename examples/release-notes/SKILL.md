# Release notes

Use only the change list supplied with the request. Group changes using the
[format guide](references/format.md). Do not invent fixes or contributors.

An optional [heading helper](scripts/headings.py) lists headings from a Markdown
file. It takes an explicit path and does not discover repositories or publish anything.

This small example is synthetic and exists to demonstrate packaging checks.
